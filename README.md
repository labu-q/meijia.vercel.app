# 甲·账本

面向小型美甲工作室的手机端记账管理工具。项目使用 React + Vite 构建，数据默认保存在浏览器 `localStorage` 中，无需后端服务。

## 功能

- 首页营业概览与日收支统计
- 收入订单、支出记录与流水筛选
- 客户管理与消费累计
- 技师业绩与提成统计
- 手机端五栏导航：首页、记账、客户、技师、我的

## 本地运行

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

构建后的静态文件位于 `dist/`，可部署至 Vercel、Netlify 等静态托管服务。

## 数据说明

当前版本仅使用本地浏览器存储：不同设备和浏览器之间不会同步；清除浏览器网站数据会一并清除账本记录。
